Modern HTML and JavaScript, unit by unit

Structure with HTML, style with CSS, behaviour with JavaScript, then ES6, TypeScript and the tools used on real projects. Five units have a demo you can run.

HTML

HTML

HTML (HyperText Markup Language) gives a page its structure. Tags mark up headings, paragraphs, links, images, lists and forms. Prefer semantic tags such as <header>, <nav>, <main>, <section> and <footer>, because they describe what the content is.

<!DOCTYPE html>
<html lang="en">
  <head>
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello, world!</h1>
    <a href="about.html">About</a>
  </body>
</html>

CSS

CSS

CSS (Cascading Style Sheets) controls how HTML looks: colour, fonts, spacing and layout. A rule is a selector plus declarations. Use Flexbox for one-dimensional layouts and Grid for two-dimensional ones. Media queries make a page respond to screen width.

.card {
  display: flex;
  gap: 1rem;
  padding: 1rem;
  border-radius: 8px;
  background: #f4f4f4;
}

@media (max-width: 600px) {
  .card { flex-direction: column; }
}

JavaScript fundamentals

JS

JavaScript is the programming language of the browser. It reacts to clicks and typing, runs timers and loads data from servers. Add it with a <script> tag, ideally an external file loaded with defer so the page is parsed first.

<script src="script.js" defer></script>

// script.js
console.log("Hello from JavaScript!");
document.title = "Changed by JS";

JavaScript statements

JS

A program is a list of statements, each one an instruction. Statements usually end with a semicolon and run in order from top to bottom. Curly braces group several statements into a block.

let a = 5;            // declaration and assignment
let b = 10;
let sum = a + b;      // expression statement
console.log(sum);     // 15

{
  let message = "Inside a block";
  console.log(message);
}

JavaScript comments

JS

Comments are notes for people, and the browser ignores them. Use them to explain why code does something, or to switch a line off while testing.

JavaScript variables

JS

Variables store values. Use const by default and let when the value changes. Avoid the older var. Names are case-sensitive, cannot start with a digit, and are usually written in camelCase.

KeywordCan be reassignedScope

const siteName = "My Site";
let visitors = 0;
visitors = visitors + 1;   // fine
// siteName = "Other";     // TypeError: assignment to constant

JavaScript data types

JS

JavaScript has seven primitive types: string, number, boolean, undefined, null, bigint and symbol. Everything else is an object, including arrays and functions. The typeof operator reports a value's type.

typeof "hello";      // "string"
typeof 42;           // "number"
typeof true;         // "boolean"
typeof undefined;    // "undefined"
typeof null;         // "object"  (a long-standing quirk)
typeof [1, 2, 3];    // "object"  (use Array.isArray)
typeof {};           // "object"

JavaScript operators

JS

Operators work on values. The main groups are arithmetic (+ - * / % **), assignment (= += -=), comparison (== === != !== > <) and logical (&& || !). Prefer === to ==, because it does not convert types first.

Control flow

JS

Control flow decides which code runs and how often. Use if, else if, else and switch to choose between paths. Use for, while and for...of to repeat.

if (marks >= 75) {
  grade = "Distinction";
} else if (marks >= 40) {
  grade = "Pass";
} else {
  grade = "Fail";
}

for (let i = 1; i <= 3; i++) {
  console.log("Round " + i);
}

JavaScript functions

JS

A function is a reusable block of code. It can take parameters and return a value. You can write one as a declaration, as an expression, or as an arrow function.

function add(a, b) {                 // declaration
  return a + b;
}

const multiply = function (a, b) {   // expression
  return a * b;
};

const square = n => n * n;           // arrow function

console.log(add(2, 3), multiply(2, 3), square(4));

JavaScript objects

JS

An object groups related data (properties) and behaviour (methods) as key-value pairs. Read a value with dot notation or square brackets. Arrays are a special kind of object for ordered lists.

const student = {
  name: "Asha",
  course: "Front-End Web Developer",
  skills: ["HTML", "CSS", "JS"],
  intro() {
    return `${this.name} is learning ${this.course}`;
  }
};

console.log(student.name);        // dot notation
console.log(student["course"]);   // bracket notation
console.log(student.intro());

Introduction to ES6

ES6

ES6 (ECMAScript 2015) modernised JavaScript. These are the features you will use most:

  • let and const
  • Arrow functions and template literals
  • Destructuring, and the spread and rest operator ...
  • Default parameters
  • Classes
  • Modules (import and export) and Promises
const user = { name: "Ravi", age: 20 };
const { name, age } = user;              // destructuring

const nums = [1, 2, 3];
const more = [...nums, 4, 5];            // spread

const greet = (who = "friend") => `Hello, ${who}!`;

class Animal {
  constructor(type) { this.type = type; }
  speak() { return `${this.type} makes a sound`; }
}

Introduction to TypeScript

TS

TypeScript is JavaScript with static types. You write .ts files, the compiler tsc checks them, and it outputs plain JavaScript that runs anywhere JavaScript runs.

// install and compile
npm install -g typescript
tsc app.ts

// app.ts
let title: string = "Hello";
let count: number = 3;
let done: boolean = false;

function add(a: number, b: number): number {
  return a + b;
}

interface Student {
  name: string;
  age: number;
}

Why TypeScript

TS
  • Bugs show up early. Type errors appear while you write, before users run the app.
  • Better editor support. Autocomplete, inline hints and safer renaming.
  • Code explains itself. Types state what a function expects and returns.
  • Scales to teams. Large codebases stay easier to change.
  • Compatible with JavaScript. Any valid JavaScript is also valid TypeScript.
function add(a: number, b: number) {
  return a + b;
}

add(2, "3");   // Error: Argument of type 'string' is not
               // assignable to parameter of type 'number'.
